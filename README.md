# Catelog Admin UI

A simple **Catelog Admin UI** built with modern web technologies.
This project allows administrators and authors to **manage products and categories** through a clean and professional interface.

## 🚀 Features

- 📦 Product Management
  - Create product
  - List products
  - Edit product
  - Delete product

- 🗂 Category Management
  - Create category
  - List categories
  - Edit category
  - Delete category

- 🧾 Client-side validation
- 🪟 Edit Product Modal
- 🪟 Edit Category Modal
- ⚠ Delete confirmation modal
- 📊 Professional Admin UI Layout with Sidebar

## 🛠 Tech Stack

### Frontend

- React.js
- TailwindCSS

### Backend

- Node.js
- Express.js
- MongoDB
